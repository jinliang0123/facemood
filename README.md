# 心語 · 人臉 × 語音 心情分析 Web App

虛擬人以心理學情境問題(暖身 → 喜 → 怒 → 哀 → 樂 → 情緒修復收尾)與受測者對話,
相機與麥克風即時分析情緒,結束後產生心情分析報告。純前端、無需建置,影音資料不離開瀏覽器。

## 執行
```bash
cd mood-app
python3 -m http.server 8080      # 然後開啟 http://localhost:8080
```
相機/麥克風需要 `localhost` 或 HTTPS。建議使用 Chrome / Edge。

## 模式
- **使用者模式**:只顯示虛擬人與麥克風音量指示燈條。
- **工程模式**:正常影像、分析中影像(臉框 + 68 點)+ 喜怒哀樂平靜分數、波形/頻譜/音訊特徵、處理管線狀態、特徵說明表。
- 對話中 `E` 切換模式、`N` 下一題、`Esc` 結束並出報告。

## 用什麼特徵分析心情
| 通道 | 特徵 | 用途 |
|---|---|---|
| 臉部 | 表情 CNN 7 類機率(開心/驚訝/生氣/厭惡/悲傷/恐懼/中性) | 決定情緒類別 |
| 臉部 | 68 特徵點幾何:嘴角上揚、嘴開合 MAR、眉高、眉間距、眼開度 EAR、眨眼、頭部運動 | 修正微笑強度、估計覺醒度 |
| 語音 | 音量 dB、基頻 F0 與變化、語速、頻譜重心(相對受測者自身基準的 z 分數) | 估計覺醒度(強度) |
| 語意(選用) | STT 文字的正/負面關鍵詞 | 報告參考 |

融合:高覺醒的愉悅 = 喜,低覺醒的愉悅 = 樂;怒、哀來自對應表情機率;EMA 平滑,每 0.2 秒取樣。
**門檻為經驗值,尚未以大量真人資料校準;結果僅反映外在表現,非醫療/心理診斷。**
